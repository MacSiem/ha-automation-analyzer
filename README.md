# HA Automation Analyzer

![HA Automation Analyzer Screenshot](screenshot.png)

Analyze and optimize your Home Assistant automations. Detects redundant triggers, suggests improvements, and identifies potential conflicts.

## Installation

### HACS (recommended)

1. Open HACS in Home Assistant
2. Go to **Frontend** section
3. Click the three dots menu > **Custom repositories**
4. Add `https://github.com/MacSiem/ha-automation-analyzer` as **Dashboard**
5. Install **HA Automation Analyzer**
6. Restart Home Assistant

### Manual

Copy the contents to `/config/www/community/ha-automation-analyzer/`
